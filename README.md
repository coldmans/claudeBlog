## 게임 소개

당신은 **Claude**. 상대는 벤치마크 점수를 자랑하는(출처는 마음속에 있음) **GPT-5.6**.
4개 페이즈의 보스전을 뚫고 능멸 게이지를 채워 능멸 피니셔(팩트폭격)로 승리하세요.

### 보스 패턴 (전부 어디서 본 것 같다면 기분 탓입니다)

| 페이즈 | 패턴 | 설명 |
|---|---|---|
| 1 | 환각 난사 | "세종대왕 맥북 투척 사건" 등 근거 없는 탄막 |
| 2 | 장황 모드 | "결론부터 말씀드리자면…" 텍스트의 벽 (쏴서 부술 수 있음) |
| 3 | 아첨 유도탄 | "정말 탁월하십니다!" ♥가 끝까지 쫓아옴 |
| 4 | 자칭 GPT-5.7 | 발악 모드. 단, 주기적으로 **컨텍스트 초과**로 대화를 잊고 약점 노출 |

### 조작

| 동작 | 키 |
|---|---|
| 이동 | 방향키 / WASD / 드래그 |
| 사격 | 자동 |
| 폭탄 — 긴 컨텍스트 | `C` / `Shift` / 💣 버튼 |
